Paste it where you want the line to appear: it’s added to the element that holds the script. With data-target, or with data-auto="false" and your own peaceJS() call, the script can go anywhere.

    

  






  
On your site

  
Two ways it sits in a footer. The symbol shows the words when hovered or tapped.

  

    
    
  






  
Options

  

    
data-themeauto · black · white · red · green · blueText colour. auto (default) is black, or white on dark pages.

    
data-darkbackground · deviceHow auto goes white: when the colour behind it is dark, or whenever the device is in dark mode.

    
data-styletext · symbolTen words, or a single peace sign that reveals them.

    
data-targetany CSS selectorWhere to inject. Defaults to the script tag’s parent.

    
data-link_blank · _self · falseHow the line links back here.

    
data-autotrue · falseTurn off and call peaceJS() yourself. It takes an options object, a DOM element or a CSS selector. Got a jQuery object or a list of elements? Pass one element (list[0]) or the selector.

  


peaceJS();                          // same as autoloading
peaceJS('#footer');                 // a selector
peaceJS(document.querySelector('footer')); // or an element
peaceJS({ target: '#header', theme: 'blue', style: 'symbol', link: false });
